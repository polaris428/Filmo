# 갤러리

## 사용자 관점

사용자는 Filmo로 촬영한 사진을 앱 안에서 다시 확인하고 필요 없는 사진을 삭제할 수 있다. 저장된 사진은 기기 갤러리에서도 확인할 수 있어야 한다.

## 제공 기능

- 앱에서 촬영한 사진 목록을 보여준다.
- 사진을 선택하면 상세 화면에서 크게 볼 수 있다.
- 사진 상세 화면에서 삭제할 수 있다.
- 촬영한 사진은 기기 갤러리에 저장되어 외부 앱에서도 접근 가능하다.

## 정상 흐름

1. 사용자가 갤러리 화면으로 이동한다.
2. 앱이 촬영한 사진 목록을 최신순으로 보여준다.
3. 사용자가 사진을 선택한다.
4. 앱이 사진 상세 화면을 보여준다.
5. 사용자가 삭제를 선택하면 확인 후 사진을 삭제한다.

## 예외 흐름

| 상황 | 사용자에게 필요한 동작 |
| --- | --- |
| 촬영한 사진이 없음 | 빈 상태 화면을 보여주고 카메라로 돌아갈 수 있게 한다. |
| 사진 로드 실패 | 해당 항목을 오류 상태로 표시하거나 목록에서 제외한다. |
| 삭제 실패 | 삭제 실패 상태와 재시도 동작을 제공한다. |
| 외부에서 사진이 삭제됨 | 앱 목록에서도 더 이상 접근하지 않도록 갱신한다. |

## 완료 기준

- 촬영 후 갤러리로 이동하면 새 사진이 목록에 표시된다.
- 사진 목록은 최신 촬영순으로 정렬된다.
- 상세 화면의 사진은 왜곡 없이 표시된다.
- 삭제 후 목록과 상세 화면 상태가 일관되게 갱신된다.
