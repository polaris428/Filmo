# Filmo 도메인 기능 문서

이 문서는 Filmo를 사용하는 사용자의 관점에서 기능을 정리한다. 구현 기술, 레이어, 클래스 구조는 `doc/plan/architecture.md`에서 다루고, 이 폴더는 사용자가 앱에서 수행하는 행동과 기대 결과를 기준으로 작성한다.

## 기능 문서

| 기능 | 문서 | 사용자 가치 |
| --- | --- | --- |
| 카메라 프리뷰 | [camera-preview.md](./camera-preview.md) | 필름 효과가 적용된 화면을 실시간으로 확인한다. |
| 필름 선택 | [film-selection.md](./film-selection.md) | 원하는 필름 감성을 선택하고 즉시 비교한다. |
| 촬영 | [capture.md](./capture.md) | 현재 보이는 필름 효과 그대로 사진을 남긴다. |
| 갤러리 | [gallery.md](./gallery.md) | 촬영한 사진을 다시 보고 관리한다. |

## 사용자 목표

- 사용자는 앱을 열자마자 카메라 화면을 볼 수 있다.
- 사용자는 촬영 전에 필름 효과를 실시간으로 비교할 수 있다.
- 사용자는 선택한 필름 효과가 적용된 사진을 저장할 수 있다.
- 사용자는 앱 안에서 촬영한 사진을 다시 확인하고 삭제할 수 있다.

## 공통 원칙

- 사용자는 기술적인 처리 과정을 알 필요가 없어야 한다.
- 필름 선택, 촬영, 저장 결과는 사용자가 즉시 이해할 수 있어야 한다.
- 권한, 저장 실패, 카메라 오류처럼 막히는 상황은 명확한 상태와 재시도 방법을 제공해야 한다.
- 촬영 전 프리뷰와 저장된 결과물의 색감 차이는 최소화해야 한다.
