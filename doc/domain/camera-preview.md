# 카메라 프리뷰

## 사용자 관점

사용자는 앱을 실행하면 카메라 화면을 통해 현재 장면을 볼 수 있다. 선택된 필름 효과는 프리뷰에 실시간으로 적용되어, 촬영 전에 결과물을 예측할 수 있어야 한다.

## 제공 기능

- 후면 카메라를 기본으로 실행한다.
- 카메라 권한이 허용되면 즉시 프리뷰를 보여준다.
- 선택된 필름 효과를 프리뷰에 실시간 반영한다.
- 전면/후면 카메라 전환을 제공한다.
- 사용자가 화면을 탭하면 해당 위치에 초점을 맞춘다.

## 정상 흐름

1. 사용자가 앱을 실행한다.
2. 앱이 카메라 권한 상태를 확인한다.
3. 권한이 있으면 카메라 프리뷰를 시작한다.
4. 기본 필름 효과가 프리뷰에 적용된다.
5. 사용자는 장면을 보면서 필름을 바꾸거나 촬영할 수 있다.

## 예외 흐름

| 상황 | 사용자에게 필요한 동작 |
| --- | --- |
| 카메라 권한이 없음 | 권한 요청 화면 또는 안내를 보여준다. |
| 사용자가 권한을 거부함 | 카메라를 사용할 수 없다는 상태와 설정 이동 방법을 제공한다. |
| 카메라 초기화 실패 | 재시도 동작을 제공한다. |
| 프리뷰 렌더링 실패 | 촬영을 막고 오류 상태를 표시한다. |

## 완료 기준

- 앱 진입 후 권한이 있으면 카메라 프리뷰가 표시된다.
- 필름 변경 시 프리뷰가 멈추지 않고 효과가 바뀐다.
- 전면/후면 전환 후에도 현재 선택된 필름 효과가 유지된다.
- 탭 포커스 입력 후 사용자가 초점 변경을 인지할 수 있다.
