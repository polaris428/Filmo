# 촬영

## 사용자 관점

사용자는 현재 프리뷰에 보이는 장면과 필름 효과를 그대로 사진으로 남길 수 있다. 촬영 순간에는 실제 필름 카메라를 사용하는 듯한 피드백을 받아야 한다.

## 제공 기능

- 셔터 버튼으로 사진을 촬영한다.
- 촬영 결과에는 현재 선택된 필름 효과가 적용된다.
- 촬영 시 셔터음과 진동 피드백을 제공한다.
- 촬영 직후 인화 느낌의 애니메이션을 보여준다.
- 촬영한 사진은 기기 갤러리에 저장된다.
- 저장 완료 후 앱 내 갤러리에서도 확인할 수 있다.

## 정상 흐름

1. 사용자가 프리뷰에서 장면과 필름 효과를 확인한다.
2. 사용자가 셔터 버튼을 누른다.
3. 앱이 현재 프리뷰 상태를 기준으로 사진을 캡처한다.
4. 셔터음, 진동, 인화 애니메이션을 제공한다.
5. 앱이 사진을 기기 갤러리에 저장한다.
6. 저장된 사진이 앱 내 갤러리 목록에 추가된다.

## 예외 흐름

| 상황 | 사용자에게 필요한 동작 |
| --- | --- |
| 저장 권한 또는 MediaStore 저장 실패 | 저장 실패 상태와 재시도 동작을 제공한다. |
| 촬영 중 카메라가 끊김 | 촬영 실패 상태를 표시하고 프리뷰 복구를 시도한다. |
| 렌더링 결과 캡처 실패 | 사진을 저장하지 않고 다시 촬영할 수 있게 한다. |
| 저장 시간이 오래 걸림 | 저장 중 상태를 표시하고 중복 셔터 입력을 막는다. |

## 완료 기준

- 저장된 사진은 촬영 당시 선택한 필름 효과를 포함한다.
- 촬영 직후 사용자는 촬영이 발생했다는 피드백을 명확히 받는다.
- 저장 성공/실패 상태가 사용자에게 전달된다.
- 연속 터치로 중복 저장이나 깨진 이미지가 생기지 않는다.
