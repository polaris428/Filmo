# 필름 선택

## 사용자 관점

사용자는 촬영 전에 여러 필름 감성을 비교하고 원하는 필름을 선택할 수 있다. 선택 결과는 별도 적용 버튼 없이 프리뷰에 즉시 반영되어야 한다.

## 제공 기능

- 화면 하단에 필름 목록을 가로 스크롤로 제공한다.
- 각 필름은 이름과 미리보기 썸네일을 가진다.
- 필름을 선택하면 프리뷰에 즉시 적용된다.
- 현재 선택된 필름은 목록에서 명확히 구분된다.

## 필름 목록

| 필름 | 사용자에게 보이는 느낌 |
| --- | --- |
| Kodak Portra 400 | 따뜻하고 부드러운 인물 사진 느낌 |
| Fuji Velvia 50 | 선명하고 채도가 높은 풍경 사진 느낌 |
| Ilford HP5 | 대비가 강한 클래식 흑백 사진 느낌 |
| Lomography | 강한 비네팅과 색수차가 있는 로모 사진 느낌 |
| Expired Film | 색이 바래고 불균일한 빈티지 사진 느낌 |

## 정상 흐름

1. 사용자가 카메라 화면 하단의 필름 목록을 본다.
2. 사용자가 원하는 필름을 선택한다.
3. 선택된 필름 표시가 갱신된다.
4. 카메라 프리뷰에 선택한 필름 효과가 즉시 적용된다.
5. 사용자는 변경된 프리뷰를 보고 촬영 여부를 결정한다.

## 예외 흐름

| 상황 | 사용자에게 필요한 동작 |
| --- | --- |
| 필름 썸네일 로드 실패 | 기본 썸네일 또는 필름 이름만 표시한다. |
| 필름 적용 실패 | 이전 필름을 유지하고 오류 상태를 표시한다. |
| 렌더링 중 필름을 빠르게 변경함 | 마지막으로 선택한 필름만 최종 적용한다. |

## 완료 기준

- 사용자는 현재 어떤 필름이 선택됐는지 알 수 있다.
- 필름 선택 후 프리뷰가 즉시 변경된다.
- 필름 목록 스크롤과 선택 동작이 촬영 버튼 사용을 방해하지 않는다.
- 앱을 사용하는 동안 선택된 필름 상태가 카메라 전환 후에도 유지된다.
