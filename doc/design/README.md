# Filmo 디자인 문서

이 폴더는 도메인 기능 명세와 기능 단위 플랜을 바탕으로 UI 설계 기준을 정리한다.

## 문서 구성

- [디자인 가이드라인](./design-guidelines.md): 디자인 컨셉, 폰트 시스템, 컬러 시스템, spacing/radius/motion 토큰
- [디자인 컴포넌트](./design-components.md): 버튼, 패널, 토스트, 다이얼로그, 썸네일 등 재사용 컴포넌트 명세
- [화면 디자인 명세](./screen-designs.md): 재사용 컴포넌트를 조합한 화면별 배치 명세

## 설계 기준

- Filmo는 카메라 앱이므로 첫 화면의 중심은 항상 프리뷰다.
- 장식보다 촬영, 필름 선택, 저장 결과 확인의 흐름을 우선한다.
- 화면 위 UI는 프리뷰를 가리되 사용자의 장면 판단을 방해하지 않아야 한다.
- 필름 감성은 UI 장식보다 실제 프리뷰와 결과 이미지에서 드러나야 한다.
